# 요구사항 명세 — orbit-pass-sim

> 각 요구사항은 **시험으로 판정할 수 있게** 수치 기준을 붙인다.
> 시험 코드는 `@Tag("REQ-…")` 로 요구사항을 가리키고, `tools/trace.py` 가 이 문서와 JUnit 결과를 대조해
> [`traceability.md`](traceability.md) 를 만든다. **시험이 하나도 없는 요구사항이 있으면 빌드가 실패한다.**

## 1. 기능 요구사항

### 케플러 풀이 (KEP)

| ID | 요구사항 | 판정 기준 |
|---|---|---|
| REQ-KEP-01 | 0 ≤ e < 1 인 모든 e 와 임의의 M 에 대해 케플러 방정식 해 E 를 구한다 | 잔차 \|E − e·sinE − M\| < 1e-11 |
| REQ-KEP-02 | 해는 독립적인 수치 방법으로 구한 값과 일치한다 | 차이 < 1e-9 rad |
| REQ-KEP-03 | E ↔ ν 변환은 서로 역변환이다 | 왕복 차이 < 1e-12 rad |
| REQ-KEP-04 | 범위 밖 이심률·NaN 입력은 거부한다 | `IllegalArgumentException` |

### 궤도 요소 (ELM)

| ID | 요구사항 | 판정 기준 |
|---|---|---|
| REQ-ELM-01 | 주기 T = 2π√(a³/μ) 를 계산한다 | 정지궤도 반경의 T = 항성일 ±1 s, ISS 급 T = 92.8 ±0.2 분 |
| REQ-ELM-02 | 물리적으로 불가능한 요소(근지점 ≤ 지구 반경, e∉[0,1), i∉[0,π], 비유한값)는 생성 단계에서 거부한다 | `IllegalArgumentException`, 경계값 e=0·i=0·i=π 는 허용 |

### 궤도 전파 (PRP)

| ID | 요구사항 | 판정 기준 |
|---|---|---|
| REQ-PRP-01 | 궤도 요소와 경과 시간으로 ECI 위치·속도를 구한다 | 에포크 r = a(1−e) · 반주기 r = a(1+e) (1e-6 km) |
| REQ-PRP-02 | 이체 운동의 보존량을 지킨다 | 비에너지 상대오차 < 1e-10, 비각운동량 벡터 변화 < 1e-10·\|h\| |
| REQ-PRP-03 | 한 주기 뒤 상태가 처음으로 돌아온다 | 위치 < 1e-6 km, 속도 < 1e-9 km/s |
| REQ-PRP-04 | 해석해 전파는 독립적인 수치 적분(RK4) 결과와 일치한다 | 위치 차이 < 0.01 km |
| REQ-PRP-05 | **장기 전파(최대 1000 년)에서도 예외 없이 결과를 낸다** | 예외 없음, 비에너지 상대오차 < 1e-9 |
| REQ-PRP-06 | 비유한 시간은 거부한다 | `IllegalArgumentException` |
| REQ-PRP-07 | **이체 모델의 유효 범위를 SGP4 기준과 대조해 고정한다** | 에포크 상태 일치 < 1e-5 km · 위치 차이 단조 증가 · ISS 급 1 h < 100 km / 24 h < 1,600 km · 대전 패스 \|ΔAOS\| ≤ 180 s · \|Δ최대고도각\| ≤ 20° (골든: `tools/gen_golden_sgp4.py`) |

### 좌표 변환 (FRM)

| ID | 요구사항 | 판정 기준 |
|---|---|---|
| REQ-FRM-01 | ECI↔ECEF, 측지↔ECEF 변환은 서로 역변환이다 | 왕복 차이 < 1e-9 km, 각도 < 1e-12 rad |
| REQ-FRM-02 | 지구 자전각은 항성일마다 한 바퀴 돈다 | ±1e-6 rad |
| REQ-FRM-03 | **각도 정규화 결과는 모든 유한 입력에 대해 [0, 2π) 안이다** | 0 ≤ θ < 2π (2π 포함 금지) |

### 지상국 관측 (GST)

| ID | 요구사항 | 판정 기준 |
|---|---|---|
| REQ-GST-01 | 위성의 고도각·방위각·거리를 구한다 | 천정 위성 90°, 적도 지상국 정북 0°·정동 90°·정서 270° (1e-9°) |
| REQ-GST-02 | **고도각은 [−90°, 90°], 방위각은 [0°, 360°) 안이다** | 무작위 입력 10,000 건에서 위반 0 |
| REQ-GST-03 | 잘못된 지상국 좌표·이름은 거부한다 | `IllegalArgumentException` |

### 패스 예측 (PAS)

| ID | 요구사항 | 판정 기준 |
|---|---|---|
| REQ-PAS-01 | 시간 창에서 가시 구간(AOS·LOS·최대 고도각)을 찾는다 | ISS 급 궤도·대전: 하루 3~8 패스, 각 ≤ 12 분 |
| REQ-PAS-02 | AOS·LOS 는 최소 고도각 경계에 있다 | 해당 시각 고도각 = 마스크 ±0.5° |
| REQ-PAS-03 | 결과는 탐색 간격에 강건하다 | 10 s vs 60 s: 패스 수 동일, AOS·LOS 차이 ≤ 2 s |
| REQ-PAS-04 | 패스는 시간순이고 겹치지 않으며, 마스크를 올리면 패스 수가 늘지 않는다 | 순서·단조성 위반 0 |
| REQ-PAS-05 | 정지궤도처럼 항상 보이는 위성은 창 전체를 한 패스로 낸다 | 패스 1개, [start, end] |
| REQ-PAS-06 | 잘못된 창·간격·마스크(NaN 포함)는 거부한다 | `IllegalArgumentException` |

## 2. 품질 요구사항 (시험 기준)

| ID | 요구사항 | 기준 |
|---|---|---|
| QR-01 | 컴파일 경고 0 | `javac -Xlint:all -Werror` |
| QR-02 | 구조 커버리지 | 라인 ≥ 90 %, 분기 ≥ 85 % (JaCoCo) |
| QR-03 | 시험의 결함 검출력 | 뮤테이션 점수 ≥ 80 % (PIT, STRONGER) |
| QR-04 | 정적 분석 | PMD 위반 0, SpotBugs 0 |
| QR-05 | 추적성 | 모든 REQ 에 통과한 시험 ≥ 1 |
| QR-06 | 이식성 | Linux·Windows × JDK 21 에서 동일 결과 |

## 3. 범위 밖

J2·대기항력 섭동, 세차·장동·극운동, 타원체 지구(WGS-84 측지), TLE/SGP4, 대기 굴절, 시각 체계(UTC·TT) 변환.
