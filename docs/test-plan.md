# 시험 계획서 — orbit-pass-sim

> IEEE 829 의 시험 계획 항목을 이 프로젝트 규모에 맞게 줄였다. 결과는 [`test-report.md`](test-report.md), 요구사항은 [`requirements.md`](requirements.md).

## 1. 시험 대상

| 항목 | 내용 |
|---|---|
| SW | `orbitsim` 패키지 — KeplerSolver · OrbitalElements · TwoBodyPropagator · J2Propagator · Frames · GroundStation · PassPredictor · Vector3 · StateVector |
| 제외 | `Main` (데모 CLI, 로직 없음) |
| 기준 문서 | `docs/requirements.md` 기능 요구사항 REQ-* 29개 · 품질 요구사항 QR-01~06 |

## 2. 시험 목표

1. 모든 기능 요구사항이 최소 1개의 **통과한** 시험으로 검증된다 (추적성 자동 검사).
2. 시험의 기대값은 구현과 **독립된 근거**에서 온다 — 구현 결과를 복사해 기대값으로 쓰지 않는다.
3. 구조 커버리지뿐 아니라 **결함 검출력**(뮤테이션 점수)을 측정한다.
4. 정상 범위 밖(경계·비유한값·장기 전파·극단 크기)에서 계약이 지켜지는지 확인한다.

## 3. 시험 기법과 기대값의 출처

| 기법 | 기대값의 출처 | 적용 대상 |
|---|---|---|
| 해석해 대조 | 닫힌 형태의 공식 (e=0 → E=M, T=2π√(a³/μ), 근지점·원지점 반경) | KEP · ELM · PRP-01 |
| 보존량 검사 | 물리 법칙 (비에너지 −μ/2a, 비각운동량 벡터) | PRP-02 |
| 독립 구현 대조 | Python 이분법(케플러), Python RK4 수치 적분(전파) — 케플러 방정식을 쓰지 않는 방법 | KEP-02 · PRP-04 |
| 왕복·역변환 | 변환 쌍의 합성 = 항등 | KEP-03 · FRM-01 |
| 기하학적 독립 기저 | 국지 동·북·천정을 외적으로 따로 구성 | GST-01 |
| 경계값 분석 | 명세의 범위 끝, 바로 밖, NaN·±∞, −0.0 | ELM-02 · GST-03 · PAS-06 · FRM-03 |
| 성질 기반 무작위 시험 | 고정 시드 난수로 넓은 입력 공간에서 불변식 검사 (최대 100,000 건) | KEP-01 · FRM-03 · GST-02 · PRP-05 |
| 시나리오 시험 | 알려진 운용 사실 (ISS 급 궤도 하루 패스 수, 정지궤도 상시 가시) | PAS-01 · PAS-05 |
| 메타모픽 시험 | 입력 변화와 출력 변화의 관계 (마스크↑ → 패스 수↓, 탐색 간격 변화 → 결과 불변) | PAS-03 · PAS-04 |
| 외부 표준 모델 대조 | SGP4 (공개 TLE + Python `sgp4`) — 제품 코드에는 없고 기준으로만 | PRP-07 · PRP-08 · PRP-09 |
| 차분 시험 | 같은 명세로 만든 다른 언어 구현 (Java ↔ C#, 520 사례) | DIF-01 · DIF-02 |
| 뮤테이션 시험 | PIT STRONGER 연산자로 코드를 일부러 망가뜨려 시험이 잡는지 | 전체 |

## 6. 결함 관리

- 결함은 **먼저 실패하는 시험으로 재현**하고(RED), 수정 뒤 같은 시험으로 확인한다(GREEN). 수정 전 실행 로그는 `docs/evidence/` 에 남긴다.
- 시험 자체의 결함(틀린 기대값·무효한 입력 조합)과 제품 결함을 구분해 기록한다.
- 커버리지·뮤테이션에서 잡히지 않은 항목은 **(a) 시험 보강 (b) 동등 뮤턴트 (c) 도달 불가 방어 코드** 중 하나로 판정하고 근거를 남긴다.

## 7. 위험과 한계

| 위험 | 대응 |
|---|---|
| 이체 모델이라 실제 궤도와 오차 | 범위를 명세에 명시하고, 공개 TLE 의 SGP4 와 대조해 유효 범위를 수치로 고정했다 (보고서 §7) |
| 독립 구현도 같은 개념 오류를 공유할 수 있음 | 방법이 다른 기준을 둘 이상 사용 (해석해 · 수치 적분 · 물리 보존량) |
| 무작위 시험의 재현성 | 고정 시드, 실패 메시지에 입력값 출력 |
| 도구·JDK 버전 차이 | 버전 고정, OS 2종 매트릭스 |
