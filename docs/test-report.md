## 2. 시험 중 발견한 결함과 조치

첫 실행에서 **73개 중 3개가 실패**했다. 셋 다 제품 코드가 아니라 **시험 쪽 결함**이었고, 원인을 확인한 뒤 고쳤다.

| # | 실패 | 원인 | 조치 |
|---|---|---|---|
| D-1 | `KeplerSolverTest.matchesKnownValues` M=2.0, e=0.9 기대 2.6913…, 실제 2.5224… | **기대값 자체가 틀렸다.** 손으로 적은 참고값을 검증 없이 넣었다 | 같은 방정식을 Python 이분법(뉴턴법과 다른 알고리즘)으로 1e-15 까지 풀어 기대값을 다시 만들고, 대조점을 4개로 늘렸다. 두 구현이 전부 일치 → 구현이 맞고 기대값이 틀렸음을 확인 |
| D-2 | `specificEnergyConserved` e=0.9 에서 `IllegalArgumentException` | 시험용 궤도(a=20000 km, e=0.9)의 근지점이 2000 km 로 **지구 안**. 유효성 검사가 정상적으로 거부한 것 | 장반경을 80000 km 로 올려 모든 e 에서 근지점이 지표 위가 되게 함. 유효성 검사가 실제로 동작함을 보여 준 사례 |
| D-3 | `angularMomentumConserved` e=0.8 에서 같은 예외 | D-2 와 같음 (a=15000, 근지점 3000 km) | 장반경 40000 km |

**교훈**: 기대값은 코드 밖의 독립 근거(해석해·다른 알고리즘)에서 가져온다. 파라미터화 시험은 모든 조합이 유효한 입력인지 먼저 확인한다.

## 3. 커버리지 분석으로 보강한 것

첫 합격(라인 92.2% · 분기 88.0%) 뒤 JaCoCo HTML 에서 놓친 분기를 줄 단위로 확인했다.

| 위치 | 놓친 분기 | 판단 | 조치 |
|---|---|---|---|
| `GroundStation` L15 경도 검사 | 하한 쪽 (−180.1) | 상한만 시험했다 — **경계값 시험 누락** | 위도 −90.1 · 경도 −180.1 추가 |
| `GroundStation` L18 고도 검사 | NaN·∞ 쪽 | 비유한값 시험 누락 | NaN · +∞ 추가 |
| `PassPredictor` L32 최소 고도각 검사 | 하한 쪽 (−90.1) | 경계값 시험 누락 | −90.1 · NaN 마스크 · NaN 창·스텝 추가 |
| `KeplerSolver` L40 비수렴 예외 | 루프를 끝까지 도는 경로 | **정상 입력(0 ≤ e < 1)에서는 도달하지 않는 방어 코드.** 뉴턴법은 e<1 이면 선택한 초기값에서 수렴한다. 시험으로 억지로 도달시키려면 반복 상한을 외부에서 바꿔야 해 설계를 해친다 | 시험 추가하지 않음. 커버리지 예외로 기록 |
| `Main` 전체 | 데모 CLI | 출력용, 로직 없음 | 시험 대상에서 제외. 게이트는 포함한 채로 통과 |

보강 후 분기 커버리지 **88.0% → 91.0%**, `Main` 을 뺀 분기 91/92 (남은 1개는 위 비수렴 방어 코드).

## 4. 정적 분석

| 도구 | 첫 결과 | 조치 |
|---|---|---|
| PMD quickstart | 18 건 — 중괄호 없는 `if` 11, 한 줄 다중 선언 5, `LogicInversion` 2 | 중괄호·선언은 고침. `LogicInversion` 은 **규칙을 제외**: `!(end > start)` 는 NaN 도 거부하려는 의도적 표현이고, 권고대로 `end <= start` 로 바꾸면 NaN 이 통과한다. 이유를 규칙 파일과 코드 주석에 남김 |
| SpotBugs | 0 건 | — |

**도구 호환성 이슈**: 로컬 기본 JVM(Java 26)에서 SpotBugs 4.9 가 `Unsupported class file major version 70` 으로 JDK 클래스를 읽지 못했다. 빌드 스크립트가 JVM 버전을 감지해 24 초과면 SpotBugs 를 건너뛰고 이유를 출력하게 했고, 로컬에서는 JDK 21 휴대용으로, CI 에서는 JDK 21 로 돌린다.
